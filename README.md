# 🎯 拼豆图纸生成器 (Pindou Beads Generator)

> 照片一键变拼豆图纸 · MARD 色号适配 · 色号预算控制

纯浏览器端拼豆图纸生成工具，上传照片自动转换为带色号标注的像素图纸，可自由控制网格精度、颜色数量和色板范围。**无需后端，部署即用。**

[🔗 在线体验](https://cheese0920.github.io/pindou-beads)（GitHub Pages）

---

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 📸 **上传图片** | 拖放或点击上传 JPG/PNG/GIF，自动居中处理 |
| 📐 **图纸规格** | 52×52 标准格 / 104×104 精细格，自动按原图比例保留宽高比 |
| 🎨 **色板规格** | MARD 全色板 291 色 / 168 色 / 144 色 / 96 色（基于官方档位表） |
| 💰 **色号预算** | 24-96 色自由调节，预算越大保留色彩越丰富 |
| 📊 **图表说明** | 导出图含顶部坐标轴 + 左侧坐标轴 + 每 10 格红色分割线 + 底部色号图例 |
| 🏷️ **色号标注** | 格子内 MARD 色号 + 中文色名（如 `A01 黄`），黑色统一可打印 |
| 📋 **色号统计** | 百分比 + 数量排行，点击排除/恢复颜色，实时自动重算 |
| 🗺️ **色号分布** | 6×8 缩略图，全局颜色布局一目了然 |
| 🖼️ **导出图纸** | 下载带完整图表说明的 PNG 图纸 |
| 🛒 **导出清单** | 下载采购清单 PNG（色号 × 色块 × 数量） |
| 🖥️ **移动端优先** | 单列布局 + 大触控目标，手机操作流畅 |

## 🔬 算法亮点

- **CIEDE2000 ΔE00**：国际标准感知色差公式，比普通 RGB 欧氏距离更接近人眼判断
- **K-means LAB 空间聚类**：在 CIELAB 颜色空间做聚类预算合并，保留自然色族
- **Farthest-First 初始化**：确定性种子选择，每次跑结果一致
- **平均色采样**：每格取区域内像素平均值，避免 JPEG 噪点导致暗色占优
- **自动去白边**：作品集图片自动识别并裁剪四周白色边缘

## 🚀 本地运行

```bash
# 克隆项目
git clone https://github.com/cheese0920/pindou-beads.git
cd pindou-beads

# 安装依赖
npm install

# 启动开发服务器
npm run dev
# → http://localhost:5173

# 构建生产版本
npm run build

# 预览构建产物
npm run preview
```

## 📁 项目结构

```
src/
├─ main.tsx                    # React 入口
├─ App.tsx                     # 单页主应用（作品集→上传→参数→结果）
├─ styles/index.css            # 浅色玻璃拟态样式
├─ algorithms/
│  ├─ colorDistance.ts         # CIEDE2000 ΔE00 色差
│  ├─ pixelation.ts            # 像素化 + K-means 预算合并
│  └─ exportImage.ts           # 导出图纸 PNG + 采购清单
├─ data/mardPalette.ts         # MARD 291 色映射表 + 中文色名
└─ utils/imageTrim.ts          # 自动去白边工具
```

## 📖 使用流程

```
作品集 → 点击"开始创作" → 上传图片 → 调整参数 → 自动生成 → 查看结果 + 下载
```

### 参数说明

| 参数 | 默认值 | 范围 |
|---|---|---|
| 网格规格 | 52 格 | 52 / 104 |
| 色号预算 | 64 色 | 24-96（步长 4） |
| 色板规格 | 291 全色 | 291 / 168 / 144 / 96 |
